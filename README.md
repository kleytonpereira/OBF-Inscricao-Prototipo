# OBF 2026, inscrição e aplicação de provas: recriação acessível (protótipo de pesquisa)

Página estática criada para pesquisa (Tópicos Avançados em Sistemas de Informação, UFC Quixadá, 2026.2). Não é o site oficial. O conteúdo pertence à Olimpíada Brasileira de Física e foi copiado em 11/11/2026 de https://app.graxaim.org/obf/2026/home.

Gerada por script a partir da página original. Usada só para rodar ASES, WAVE e Lighthouse por URL.
