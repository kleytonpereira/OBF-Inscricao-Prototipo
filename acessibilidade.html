Ir para o conteúdo

Acessibilidade desta versão

Esta é uma versão corrigida, para pesquisa, da página oficial (OBF 2026, inscrição e aplicação de provas). Não é o site oficial e não é atualizada.

Meta

Critérios de nível A e AA das Diretrizes de Acessibilidade para Conteúdo Web (WCAG) 2.2 e art. 63 da Lei Brasileira de Inclusão, mantendo o visual original.

Correções aplicadas

  • scripts do original removidos (3); links e recursos relativos tornados absolutos
  • link "Ir para o conteúdo" como primeiro elemento
  • título da página descreve o assunto (1×)
  • logotipo com texto alternativo que diz o que é (1×)
  • botão do menu móvel sem nome e dependente de JavaScript removido (menu sempre visível) (1×)
  • ícones decorativos escondidos do leitor de tela (6×)
  • "Bem-vindo(a)" passa a ser o único h1 (1×)
  • títulos dos avisos de h3 para h2 (4×)
  • conteúdo dentro de <main> (1×)
  • fim do <main> (1×)
  • imagem decorativa da coluna lateral com alt vazio (repete o nome do site) (1×)
  • links que estavam dentro de <button> viram links com o mesmo estilo de botão (9×)
  • link "aqui" passa para o texto que descreve o destino (1×)
  • link "clique aqui" passa a descrever o destino (1×)
  • link "clicando aqui" passa a descrever o destino e o formato (1×)
  • logotipo "sbf" com nome por extenso (1×)
  • logotipo "btgpactual" com nome por extenso (1×)
  • logotipo "graxaim" com nome por extenso (1×)
  • lista que estava dentro de <p> separada do parágrafo (HTML válido) (1×)
  • <strong> fechado corretamente (HTML válido) (1×)
  • link para o site da SBF em HTTPS (1×)
  • símbolo e página de acessibilidade, link para o original e aviso no rodapé

Avaliação

A verificação é feita com ASES, WAVE e Lighthouse e por inspeção manual (UFC Quixadá, 2026).
